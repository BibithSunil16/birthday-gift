📸 BIRTHDAY GIFT — PHOTO INSTRUCTIONS
========================================

The website has THREE photo sections. Each section reads from its
own folder. Drop photos into the folder, then update the matching
array in script.js (CONFIG object near the top).

PHOTO SECTIONS:

  Page 4 — Main photos (7 photos):
    Folder:    main photos/
    Array:     CONFIG.bestMoments

  Page 5 — Puzzle game (4 photos, solved one after another):
    Folder:    puzzle photos/
    Array:     CONFIG.puzzlePhotos

  Page 6 — Funny photos (8 photos):
    Folder:    funny photos/
    Array:     CONFIG.funnyPhotos

Example (edit CONFIG in script.js):
  funnyPhotos: [
    { src: "funny photos/beach-day.jpg", caption: "Our beach adventure! 😂" },
    // ... more photos
  ]

Tips:
- Use .jpg or .png files for best results
- Keep photos under 1MB if possible for faster loading
- Square or landscape photos work best (aim for ~800x600px)
- You can add/remove as many photos as you want!
- The website shows a colored placeholder for any missing photos

Enjoy! 🎉
